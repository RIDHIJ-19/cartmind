CartMind

Would you let an AI spend your money unsupervised?

Most people's answer is no — not because agents can't shop, but because nothing stops them from getting it wrong, and no one can prove what happened after.

// this talk is about closing that gap

The Impact

What CartMind actually demonstrates

A concrete, falsifiable trust boundary — not an argument that agents can be made safe, but the exact mechanism that makes them provably bounded.

7
independent, deterministic checks in front of every payment — each with a plain-English pass/fail reason
2
separate gates (cart policy + safety kernel) — a bug in one can't disable the other
100%
of blocked and captured attempts reconstructable from the audit trail

Design Doc — Security Model

Enforced today, not aspirational

✓Iframe isolation is load-bearing — card fields are never reachable from agent JS
✓Two independent gates — cart policy and the safety kernel are separate code paths
✓No implicit spend — a card must appear in this turn's conversation, never defaulted
✓Model claims are never trusted — the server verifies real HTTP responses, not prose
✓TEST MODE structurally enforced — live keys are rejected outright, no code path moves real money
✓Every decision is logged — allowed or blocked, with a plain-English reason
